User Interface Walkthrough

1. Choose Email OTP Option

A "Login with Email OTP" option appears directly on Odoo's standard login page. No separate system URLs needed.

Seamless login interface option alongside default credentials flow

2. Enter Email & Request Code

The user enters their email and taps "Verify". The server handles code generation, validation, and delivery securely.

Instant background validation checks for user registration and domain permission

3. Verify 6-Digit Code

The user receives a clean, branded email containing the secure 6-digit code. They input it directly on the verification screen.

Clean verification container ensuring safe and fast user experience

4. Resend Without Restarting

If the code expires or gets delayed, the user requests a new code with a single click without leaving the page.

Intelligent code replacement prevents multiple active codes and security loopholes

5. Auto-Created Portal Access

New contacts automatically get created as Portal Users on successful login. Zero administration effort.

Frequently Asked Questions

Does this replace standard password authentication?

No. The Email OTP login function works alongside default passwords. Users can choose either route on the sign-in page.

What happens when a new contact attempts to log in?

A corresponding Portal User profile is auto-generated in the backend database. They gain client access without admin intervention.

Can users configure the OTP code length and expiry timer?

Yes. System administrators can adjust the code duration and maximum invalid verification attempts inside system settings.

Is a third-party SMS API or mailing server provider required?

No. The module utilizes Odoo's standard outgoing mail server configuration. No external subscriptions are needed.
